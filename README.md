## Как открыть отчёт

1. Нажмите файл отчёта с расширением .docx в списке файлов.
2. Нажмите Download raw file или значок скачивания.
3. Откройте скачанный документ в Microsoft Word. Если Word предложит обновить поля, согласитесь.

## Как открыть проект

1. Нажмите ZIP-файл в списке файлов и выберите Download raw file.
2. В Проводнике Windows нажмите на архив правой кнопкой мыши, выберите Извлечь все, укажите папку и нажмите Извлечь.
3. Откройте извлечённую папку ClimateControlAudit. Дважды щёлкните ClimateControlAudit.csproj и выберите Visual Studio 2026.
4. В Обозревателе решений изучите ClimateReading.cs (модель показания), ClimateReadingService.cs (проверка и приём), Program.cs (пять проверок). AuditSample.cs.txt — намеренно небезопасный учебный фрагмент, который не компилируется.
5. Нажмите Ctrl+Shift+B для сборки, затем Ctrl+F5 для запуска без отладки.
6. В консоли должны появиться пять строк PASS и итог 5/5; принято записей: 1. При установленном .NET 10 SDK можно выполнить dotnet run --project ClimateControlAudit.csproj из папки проекта.

Ключ в Program.cs предназначен только для учебной проверки. В рабочей системе секретный ключ хранится вне исходного кода.
