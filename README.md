# Практическая работа № 3 — Climate Control

**Вариант 3.** Аудит кода модуля климат-контроля АИС «Умный кампус». В отчёте указан студент Хусаинов Арсен Ильдарович.

## Что находится в репозитории

- `ПР3_Хусаинов_Арсен_Ильдарович.docx` — готовый отчёт. В нём есть постановка задачи, таблица из десяти замечаний по коду, листинги исходного и исправленного кода, снимки Visual Studio, таблица пяти проверок и выводы.
- `ПР3_Вариант3_ClimateControl_проект.zip` — архив проекта Visual Studio. Внутри папка `ClimateControlAudit` с проектом C#, исходными файлами и учебным фрагментом для аудита.
- `README.md` — эта инструкция.

## Как открыть отчёт

1. На странице репозитория нажмите файл отчёта с расширением `.docx`.
2. Нажмите кнопку **Download raw file** или значок скачивания в правой части страницы файла.
3. Откройте скачанный файл в Microsoft Word. На второй странице находится содержание, далее идут текст, таблицы, снимки экрана и листинги. Если Word предложит обновить поля, согласитесь.

## Как открыть проект

1. На странице репозитория нажмите файл `ПР3_Вариант3_ClimateControl_проект.zip`, затем **Download raw file**.
2. В Проводнике Windows нажмите правой кнопкой мыши по архиву и выберите **Извлечь все**. Укажите удобную папку и нажмите **Извлечь**.
3. Откройте извлечённую папку `ClimateControlAudit` и дважды щёлкните файл `ClimateControlAudit.csproj`. Если Windows спрашивает, выберите Visual Studio 2026.
4. Дождитесь загрузки проекта. В **Обозревателе решений** откройте `ClimateReading.cs` (модель показания), `ClimateReadingService.cs` (проверка и приём) и `Program.cs` (пять контрольных случаев).
5. В меню Visual Studio выберите **Сборка → Собрать решение** либо нажмите **Ctrl+Shift+B**. Затем выберите **Отладка → Запуск без отладки** либо нажмите **Ctrl+F5**.
6. В консоли должны появиться пять строк `PASS` и итог `5/5; принято записей: 1`. Для запуска из терминала можно выполнить `dotnet run --project ClimateControlAudit.csproj` из извлечённой папки при установленном .NET 10 SDK.

`AuditSample.cs.txt` — намеренно небезопасный учебный фрагмент для анализа. Он не входит в компиляцию. Секретный ключ в `Program.cs` демонстрационный; в рабочей системе его следует хранить вне исходного кода.
